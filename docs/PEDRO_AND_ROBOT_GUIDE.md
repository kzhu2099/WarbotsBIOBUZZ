# PedroPathing and robot setup

The current guide is [PEDROPATHING_V3.md](PEDROPATHING_V3.md).

Field dimensions and robot measurements belong in `FieldConfig.java`. Mechanism names, motor directions, and timed actions belong in `RobotConfig.java`. Drive and Pedro calibration belong in `pedro/Constants.java`.

For changes during an event, use [MEET_QUICKSTART.md](MEET_QUICKSTART.md). For field axes, Hive positions, and path layout, use [FIELD_PATHS.md](FIELD_PATHS.md).
