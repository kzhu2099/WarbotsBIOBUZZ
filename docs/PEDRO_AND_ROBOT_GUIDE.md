# PedroPathing and field setup

The PedroPathing 3 setup is now documented in [PEDROPATHING_V3.md](PEDROPATHING_V3.md).

Field coordinates and robot dimensions belong in `FieldConfig.java`. Hardware names, motor directions, and timed mechanism settings belong in `RobotConfig.java` and `pedro/Constants.java`.

For testing the code during an event, use [MEET_QUICKSTART.md](MEET_QUICKSTART.md).
